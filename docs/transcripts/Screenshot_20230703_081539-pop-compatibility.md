# Screenshot_20230703_081539_Photos.jpg — "Simplified Myers Briggs Type Compatibility Chart"
**Group B · diagram_reference · confidence: high · ⛔ not for ingestion**

A 16×16 colour-block compatibility grid with a five-level legend: "Uh-Oh, Think This One Through" ·
"It Could Work, But Not Ideal" · "One Sided Match" · "It's Got a Good Chance" · "Often Listed as an
Ideal Match".

**Deliberately not ingested, and worth saying why.** Unlike `IMG_6099` — the personalitydata.org
survey, which states a method and a licence — this chart carries no source, no methodology and no
attribution. Its structure is coarse letter-blocks (the NF/NT quadrant is a solid green wall, the
S types a solid red one) rather than anything pairwise, and it contradicts both of the app's
measures at once: it places ENTP–ISFJ, which the engine rates 100 and the survey rates 5%, in the
red "Uh-Oh" band, agreeing with neither.

The app already carries one honest empirical counterweight. Adding an unsourced one would dilute
that rather than strengthen it.
